## 🟧 Trees (DFS / BFS)

**Signals:** Hierarchy, parent-child

| # | Problem |
|---|---------|
| 1 | Maximum Depth of Binary Tree |
| 2 | Invert Binary Tree |
| 3 | Diameter of Binary Tree |
| 4 | Binary Tree Level Order Traversal |
| 5 | Validate Binary Search Tree |
| 6 | Lowest Common Ancestor of a Binary Tree |

**Use DFS when the problem involves:**
    paths, subtrees,calculations from children,height,diameter,sum of paths
    DFS = Go deep in the tree
**Use BFS when the problem talks about levels. (Queue):**
    level,level order,distance,shortest path,minimum steps,nearest,breadth
**When to Use Min / Max Range**
    * Use this when the problem is about BST validation or value constraints.
    valid BST,greater than,less than,range,constraints
